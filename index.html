Set up your Zinc Store

You will get your own online store, with its own pretend payment system, running inside your web browser. You install nothing on your computer.

  • Time: about 15 minutes
  • Finish before: Thursday, Oct 8, 11:00 AM ET
  • Money: none. Every payment is fake test money.

First, which computer are you using? Click one.

The steps below change to match your keyboard.

Before you start, have these ready

  • Your laptop, plugged in, with good internet.
  • The Google Chrome browser (Microsoft Edge also works).
  • A free GitHub account. No account yet? Make one at github.com/signup. It takes 2 minutes.
  • Your CYDEO login (the one you use for the LMS).
0 of 7 done
  1. 1

    Open your lab

    Click this big button. It opens in a new tab.

    Open my lab →
    • If GitHub asks you to sign in, sign in.
    • You will see a page that says Create codespace. Click the green Create codespace button. (On some screens it says Create new codespace. Same button.)
    Opened this link before? Then you see Resume codespace and “Previous session found”. Click the green Resume this codespace. Do not click Create a new one: that makes a second, empty lab, and your work stays in the first one.
    You should see: a page that looks like a code editor (it is called VS Code), with a black box at the bottom. The black box is the terminal. You type commands there.
  2. 2

    Wait until your lab is ready

    About 3 to 4 minutes, only this first time.

    GitHub is building your lab. Do not close the tab. Do not type anything yet. Go get a glass of water.

    It is ready when the terminal at the bottom shows a quick check that ends like this:

    👋 Welcome to Codespaces! …
@yourname ➜ /workspaces/agentic-commerce-lab (main) $ npm run --silent doctor -- --brief || true
.env not found. Continuing without it.

Lab doctor: FAIL: 7 pass, 0 warn, 4 fail. Run: npm run doctor

@yourname ➜ /workspaces/agentic-commerce-lab (main) $
    The FAIL here is normal. You have not started your store or signed in yet. Steps 3 to 7 turn every line into PASS.
    No terminal at the bottom? Press Ctrl + ` (the ` key is just left of the 1 key, also on a Mac).
  3. 3

    Start your store

    Click inside the terminal. Then type this and press ReturnEnter:

    npm run dev

    Tip: click Copy, click inside the terminal, then paste with ⌘ CmdCtrl + V. If the browser asks “Allow paste?”, click Allow.

    You should see: two links, Zinc Store and Back office, and then a line that says Zinc Store on http://localhost:3000. Your own store is running, with your own Stripe test account.

    Tip: hold ⌘ CmdCtrl and click the Zinc Store link to open your store. The Back office link opens your CRM, where you see every order and customer.

    If it says “ONE CLICK NEEDED”: hold ⌘ CmdCtrl and click the link it shows. Sign in to Stripe, or make a free Stripe account, then click Allow. Come back to this tab. It keeps going by itself.
    Very important: leave this terminal alone from now on. Do not close it and do not type in it. This is terminal 1. It keeps your store alive.
  4. 4

    Look at your store

    A small box pops up in the bottom-right corner that mentions port 3000. Click Open in Browser.

    You should see: the Zinc Store in a new tab, with phones and accessories for sale. This store is yours alone.
    Missed the pop-up? Next to the terminal, click the PORTS tab. Find 3000 and click the little globe icon next to it.

    Now go back to the tab with the code editor.

  5. 5

    Open a second terminal

    At the top right of the terminal area there is a + button. Click it once.

    You should see: a new, empty terminal. This is terminal 2. You use terminal 2 for everything else. Terminal 1 keeps running your store.
  6. 6

    Sign in to the AI agent

    In terminal 2, type this and press ReturnEnter:

    cydeo login
    1. It shows a link. Hold ⌘ CmdCtrl and click the link.
    2. Sign in with your CYDEO account and click to approve.
    3. Come back to the code editor tab and wait.
    You should see: Logged in.
  7. 7

    Check that everything works

    Still in terminal 2, type this and press ReturnEnter:

    npm run doctor

    Wait about one minute. The doctor checks 13 things and prints nothing until it is done. Then every line must say PASS. It looks like this:

    PASS  Node.js 24+                  v24.21.0
PASS  Project dependencies         installed
PASS  Stripe CLI                   1.53.0
PASS  CYDEO CLI (@cydeo/cli)       0.1.6
PASS  AI Lab login                 token valid
PASS  Zinc Store running           http://localhost:3000
  … more lines …
Verdict: PASS

    Then type this one and press ReturnEnter:

    npm run check:lab -- L00

    Last thing: take a screenshot of the Verdict: PASS line and post it in #aq03-support.

    To take a screenshot on a Mac: press ⌘ Cmd + Shift + 4, then drag a box around the PASS lines. The picture lands on your Desktop.

    To take a screenshot on Windows: press Windows key + Shift + S, then drag a box around the PASS lines. Then paste it into Discord with Ctrl + V.

You are ready for Thursday.

See you at 11:00 AM ET. Your store will be waiting for you.

Bonus: watch your tests step by step

Your store must be running (terminal 1). In terminal 2, type this and press ReturnEnter:

npm run watch
  1. A new tab opens with Playwright. If it does not, click the PORTS tab and click the globe next to 8080.
  2. Click ▶ at the top of the test list to run every test.
  3. Click a test’s name. Then click any step: the big picture shows your store at that exact moment.

Leave terminal 2 running while you watch. Press Ctrl + C there to stop it.

If something goes wrong

Stuck for more than 2 minutes? Copy what the terminal says (or run npm run doctor) and post it in #aq03-support. Do not try to fix your laptop and do not install anything. Everything you need is already inside your lab.

I closed the tab. Is my work gone?

No. Your lab is saved. Go to github.com/codespaces and click your lab to open it again. If you see “Previous session found”, click Resume this codespace, never Create a new one.

Then start your store again: in a terminal, type npm run dev. Open a second terminal with + for everything else.

Coming back on Thursday: what do I do?

Your lab goes to sleep when you leave it alone for a while. That is normal.

  1. Go to github.com/codespaces and click your lab. (Or click Open my lab in step 1, then Resume this codespace.)
  2. In the terminal, type npm run dev (this is terminal 1, leave it running).
  3. Click + for terminal 2. Type npm run doctor. All PASS? You are ready.
The doctor says FAIL on “Zinc Store running”

Your store is not running. Look at terminal 1. If it stopped, type npm run dev there again, wait for Zinc Store on http://localhost:3000, then run the doctor again in terminal 2.

The doctor says FAIL on “AI Lab login”

Do step 6 again: type cydeo login in terminal 2 and approve in the browser. Wait for Logged in.

cydeo login shows a red error that says spawn xdg-open ENOENT

Your lab was built before we fixed this. Copy this one line into terminal 2 and press ReturnEnter:

curl -fsSL https://raw.githubusercontent.com/cydeo-agentic/agentic-commerce-lab/main/.devcontainer/xdg-open | sudo tee /usr/local/bin/xdg-open >/dev/null && sudo chmod 755 /usr/local/bin/xdg-open

Then do step 6 again.

The “Lab doctor” line never showed up

If it has been more than 10 minutes, take a screenshot of the whole screen and post it in #aq03-support. Leave the tab open so we can help.

npm run catchup says “Could not fetch the catch-up branch”

Your lab was built before we fixed this. Copy this one line into terminal 2 and press ReturnEnter, then run your catchup command again:

curl -fsSL https://raw.githubusercontent.com/cydeo-agentic/agentic-commerce-lab/main/scripts/catchup.mjs -o scripts/catchup.mjs
I typed a command but nothing happened (or it went into a file)

When your lab opens, the file README.md is open at the top and it takes your typing. Always click inside the black terminal first, then type. If you typed into README by accident, it does not break anything.

Paste does not work in the terminal

Click inside the terminal first, then press ⌘ Cmd + V. If that still fails, just type the command by hand. It is short.

Click inside the terminal first, then press Ctrl + V. If the browser asks to allow paste, click Allow. You can also right-click inside the terminal and choose Paste, or just type the command by hand.
